Get the game

WANDERER is a procedural open-world game of exploration, discovery and survival that runs in your browser. There is nothing to install — no launcher, no npm, no build step. Download the archive, unpack it, and serve the folder over any static web server.

Download v1.0.0 (zip) Source archive Browse the repository

Already have the files? Run node server.mjs 8080 in the folder and open http://localhost:8080/. Any static server works — the only requirement is that .js is served as text/javascript.

wanderer-1.0.0.zip · 482 KB · 68 files · sha256 __SHA__

Run it

unzip wanderer-1.0.0.zip
cd Wanderer-1.0.0
node server.mjs 8080
# → open http://localhost:8080/

Requires a browser with WebGL 2 and ES modules — current Chrome, Edge, Firefox or Safari. Node is only needed for the tiny bundled server and the test suite; the game itself is plain browser code. Once unpacked it runs entirely offline: three.js is vendored inside the archive and there are no CDN requests.

v1.0.0 — first release

The complete playable game.

  • Procedural worlds from a seed: 25 biomes (7 rare), rivers walked downhill, lakes, layered underground.
  • World-creation screen with seed control, 5 sizes, 6 types, 26 generation sliders, randomize-everything, and a live rotatable 3D preview you can hover for real ground data.
  • Continuous-LOD crack-free terrain, procedural sky with day/night and moon phases, animated water, instanced wind-blown vegetation.
  • 35 POI types placed by contextual rules — villages, ruins, dungeons, shrines, hollow spires, landmarks — with interiors, loot, lights and NPCs.
  • Full movement set, survival stats, 118 items, generated weapons with 6 rarities and 22 affixes, 80 recipes across 9 stations.
  • Real-time combat with weight, reach, arcs, parries, dodges, combos, affinities and loot.
  • Modular building with snapping and free placement, farms with crops, weather fronts, 44 creature archetypes with distance-gated AI.
  • Fully synthesised audio, discovery journal with a mystery layer, contextual tutorial, procedural quests and location-priced trade.
  • Multi-slot saves with autosave, atomic writes and crash recovery.

Tested: node tools/test.mjs — 67 checks covering generator determinism, mesher integrity, resource harvesting, POI geometry and terrain carving, build rules, farming, weather, actors, combat, save migration and the module graph. Shader compilation and final visuals need a real GPU and are not covered by the automated suite.
